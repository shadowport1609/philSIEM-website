Before sharing on LinkedIn

  • Check your contact and GitHub links lead to the intended public profile.
  • Verify each project description matches what you have personally built and tested.
  • Keep proposed tools and synthetic telemetry labelled as such.
  • Check the website on mobile and desktop and test report downloads.
  • Never publish live credentials, private IP information or sensitive honeypot logs.

Suggested LinkedIn Featured description

PhilSIEM is my independent cybersecurity learning portfolio, documenting hands-on Linux and OpenCanary lab work, a proposed security-monitoring architecture, simulated SOC investigations and a browser-based analyst training lab.

This description is suitable for a Featured link. It deliberately avoids implying that fictional investigations were real incidents.
