Practical components

What's inside the lab

01 / Linux host

A separate laptop running Ubuntu serves as a dedicated learning environment, keeping experimentation away from everyday MacBook tasks.

02 / OpenCanary

Decoy services such as SSH, FTP, HTTP and Telnet help demonstrate how service interactions can be recorded for defensive analysis.

03 / Notifications

Alert forwarding to Telegram supports timely awareness and creates an opportunity to practise basic triage and event review.

SOC investigation mindset

What happens after an alert?

  1. Validate: Determine which service generated the event and whether it is expected test traffic.
  2. Contextualise: Review available timestamps, source metadata and the type of interaction, without treating a source IP as proof of identity.
  3. Classify: Distinguish routine internet scanning, lab-generated tests and activity worth further attention.
  4. Document: Record observations, limitations and recommended next steps.
  5. Improve: Tune alert handling and update the lab notes as new tests are completed.
